📞 PhoneBookSwingApp
A simple PhoneBook application built using Java Swing. This application allows users to manage contacts by adding, deleting, and searching for them.

Features
Add Contacts: Users can add new contacts by entering a name and phone number.

Delete Contacts: Users can delete selected contacts from the list.

Search Contacts: Users can search for contacts by name. The list automatically selects the first matching contact.

Technologies Used
Java Swing: Used to create the graphical user interface (GUI).

DefaultListModel: Used to store the contacts in a list model, making it easy to add, remove, and display contacts.
